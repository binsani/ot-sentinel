# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Send a private report to the repository maintainers through GitHub's **Security > Report a vulnerability** workflow. Include affected versions, impact, reproduction steps, and any suggested mitigation. Do not include sensitive plant data, packet captures, credentials, or device addresses.

Maintainers will acknowledge a report within 3 business days, provide an initial assessment within 10 business days, and coordinate disclosure and remediation with the reporter. We ask reporters to allow 90 days for remediation before public disclosure, unless active exploitation or operational safety requires a different schedule.

Only the latest released version receives security fixes until a long-term-support policy is published. Never deploy development builds on a production control network.
